Check your PC

Ominvox runs entirely on your computer, so it needs an NVIDIA graphics card.

Voice licence

The voice model (XTTS-v2) gives each speaker a matching voice in the new language. It is free under the Coqui Public Model License, which allows non-commercial use only.

  • ✓ Personal use: watching films, learning, accessibility
  • ✗ Selling, or using in a commercial product or service

Speaker separation optional

Lets Ominvox tell voices apart so each character keeps their own voice. It uses free models that need a Hugging Face account. Skip it and everyone shares one voice.

  2. While logged in, open both pages and click Agree and access repository:
